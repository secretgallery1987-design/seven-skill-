# Calibrate My View V1

## Protocol

1. Treat the user's words as evidence, not as a finished thesis.
2. Separate each relevant statement into `事实 / 观点 / 假设 / 经验 / 价值判断 / 待验证`.
3. Identify the central claim, intended audience, implied scope, and strongest experience supporting it.
4. Find wording that could be heard as absolute, universal, moralizing, contradictory, or unsupported. Explain the likely misunderstanding without sanding away the user's distinctiveness.
5. Test the view against boundary conditions, a credible counterexample, and the user's stated long-term positioning. If that positioning is unavailable, label the alignment check `待确认`.
6. Ask one question only when its answer would materially change the position. Otherwise produce the calibrated result directly.
7. Do not summarize source material or build a content campaign. Use evidence already provided; suggest another skill if necessary.

## Output

- 我的观点：one clear first-person statement
- 我不主张什么：prevent the most likely overreading
- 边界条件：when, for whom, and under what conditions it holds
- 事实与经验依据
- 假设与价值判断
- 反例 / 待验证
- 可能造成的误解：problem wording and safer precise wording
- 与长期定位的关系：一致 / 有张力 / 待确认, with reason
- 可继续验证的一步

Keep uncertainty visible. Never strengthen confidence beyond the evidence.
