# Assetize Content Idea V1

## Protocol

1. Start from a supplied experience, knowledge record, view, or project. Do not fabricate market demand, trends, audience pain, or personal experience.
2. Identify the smallest defensible idea: one audience, one tension, one claim, and one promised change.
3. Explain why it is worth making now using available evidence. Mark unverified timing claims as hypotheses.
4. Choose a fitting content form based on the idea's job, not platform fashion.
5. Evaluate asset potential separately:
   - content asset: reusable framework, case, series, FAQ, checklist, or reference
   - product asset: template, service step, diagnostic, workshop, dataset, or tool
6. Score potential qualitatively as `低 / 中 / 高` with reasons. Do not force every idea into a product.
7. Keep the user's viewpoint intact. If the view is unclear, recommend the calibration skill instead of inventing a stronger hook.

## Output

- 选题一句话
- 为什么现在值得做
- 目标读者与具体情境
- 核心冲突
- 核心观点与证据
- 推荐内容形态与理由
- 内容结构：opening, development, proof, closing
- 内容资产潜力：低 / 中 / 高；可沉淀什么
- 产品资产潜力：低 / 中 / 高；连接方式
- 不应泛化或承诺的部分
- 最小制作动作

Prefer one strong recommendation over a long menu. Generate alternatives only when the user asks.
